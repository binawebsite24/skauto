# sk-autoworld-pj

Static single-page website, deployed on Cloudflare Workers static assets.

- `public/index.html` — the complete site (styles, scripts and images inlined)
- `wrangler.jsonc` — Cloudflare deploy config

**Live:** https://sk-autoworld-pj.bina24.workers.dev

## Deploy

```bash
npx wrangler deploy
```
